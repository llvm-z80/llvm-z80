# Tests the Z80/SM83 target structurally cannot pass.
#
#   <path-or-glob> [target] [opt] : skip=<reason>
#
# An omitted target or opt qualifier means every target / every opt level.
#
# Reasons:
#   libc           needs a hosted libc
#   gcc            depends on GCC: a builtin or language extension clang does not implement
#   unsupported    uses a feature this target deliberately refuses
#   softfloat-f64  needs 64-bit double
#   callbr         uses asm goto; no GlobalISel lowering upstream
#   int16          the test assumes a 32-bit int
#   size           does not fit in the 64 KB address space
#   nonportable    written for another architecture
#

# A `clang=<note>` line reports its failure as CLANG rather than as ours.

# `cargo run torture -run-skipped` runs only the skipped tests and reports any
# that now pass, so a wrong entry cannot hide a working test.
